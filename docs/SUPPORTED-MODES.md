# Included live modes

The captured working set contains these 16 artistic modes, without diagnostic or
benchmark duplicates. Keep the folder names and complete contents when copying.

- `FRACSHAT_ARCHITECTURAL_GHOSTS_F2`
- `GAUSSIAN GLITCH`
- `HAUTLLE_ARCHITECTURE_02_STAGE4`
- `HAUTLLE_BRAKHAGE_DRIFT_01`
- `HAUTLLE_FORMWERK_01`
- `HAUTLLE_INTERFERENCE_03`
- `HAUTLLE_MARKOV_LIVE_720_V1`
- `HAUTLLE_MASST_WALK`
- `HAUTLLE_MELTLOCK_01`
- `HAUTLLE_MURMURATION_05_FIELD`
- `HAUTLLE_RINGMOSH_VHS_V1`
- `HAUTLLE_ROBOT_FIGHT_01`
- `HAUTLLE_VECTOR_IMPACT_01`
- `KCSC_RELIQUARY_01`
- `SIGNAL_SEED_MICRO`
- `TERRAIN_MORPH`

MassSt includes `masst.dat` and its OpenStreetMap notice. KCSC includes the original
logo mesh and both shader files. Ghosts includes `core.lua` and `region_pair.lua`.
The release also includes `eyesy.lua` and `ha_palette.lua` under `modules/`, plus
the two engine-adjacent frozen-layer helpers under `source/app/bin/data/`.
No TTFs, screenshots, sample photos, or external image downloads are required.
The small `examples/` directory contains the starter and a minimal helper example.

`provenance/live-payload.json` records the exact captured file hashes. Runtime
source comments retain their original revision labels; [validation](VALIDATION.md)
records later checks without changing those payload bytes.
